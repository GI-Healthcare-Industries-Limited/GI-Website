# Public header typography

`Inter.ttf` is the Inter variable font from the Google Fonts repository,
`ofl/inter/Inter[opsz,wght].ttf`, downloaded 15 September 2026 and distributed under
the adjacent `LICENSE-Inter.txt` (SIL Open Font License). It is served locally and
used only for the public header to match the Next.js Contact page. Existing main
page typography is unchanged.
